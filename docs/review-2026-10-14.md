# 桌面分类助手 v2.6.0 代码审查与优化建议（2026-10-14）

> 审查范围：全部 6 个源文件 + tests（80 用例）。
> 基线：`python -m pytest tests/ -q` → **80 passed（2.55s）**；
> 环境：Python 3.12.10 / PySide6 6.12.0 / pypinyin 0.55.0。

## 一、已确认的 Bug（按优先级）

### BUG-1 收纳目录输入框失焦即全量重建格子（已实测复现）
`control_panel._save_root` 绑定于 `root_edit.editingFinished`。Qt 中 editingFinished
在"回车或失焦"时触发，**文本未改动也触发**（本机 Qt 6.12 实测触发 1 次）。
后果：用户每点一下别的控件（只要焦点曾经过路该输入框）→ 保存配置 + 全部格子销毁重建
闪烁一次 + watcher 全量重挂。属于高频无意义操作。
修复：文本与已保存值相同（规范化 os.path.normpath）时直接 return。

### BUG-2 配置/历史写入非原子，崩溃即丢数据
`config.save_config / save_history / append_records` 均为 truncate→dump 两步写。
写一半时崩溃/断电 → JSON 损坏 → 下次加载静默退回默认：**格子位置记忆、撤销历史全部丢失**。
修复：写临时文件 + `os.replace()` 原子替换（Windows 支持）。
顺带：`pop_last_batch` 先删记录再执行移动，移动失败则该批次不再可重试——
可改为"撤销成功后从历史中移除"，但属次要。

### BUG-3 拖入按文件逐条重写历史文件（写放大）
`main.handle_drop` 循环内每个文件各调一次 `cfg.append_records([...])`
= 每文件 1 次 load + 1 次全量 save（最多 2000 条记录的 JSON）。
拖 50 个文件 = 100 次完整读写 + 50 个非原子写窗口。
修复：拖入批次只 load 一次、append 全部、save 一次（organize 路径已是这么做的）。

### BUG-4 粘贴后无论成败清空剪切板
`main.handle_paste_files`：`paths, self.file_clipboard = self.file_clipboard, []`
先清空 → `handle_drop` 中被占用失败的文件**从剪切板丢失**，用户需重新逐个剪切。
修复：失败项保留在剪切板（或按失败路径回填）。

## 二、性能问题（含实测数据）

### PERF-1 搜索在 UI 线程同步执行，按键即全库扫描
基准（临时合成 5000 文件、40% 中文名）：
- 拼音首字母命中：26.0 ms
- **未命中（全量遍历+拼音）：113.8 ms**
- 子串命中：101.3 ms
面板搜索与搜索格子各自独立执行；且每次收纳库有任何变化，
`refresh_all()` → SearchWidget.refresh → 用当前关键词**再全库扫一遍**。
几千文件尚可，真实收纳库到文件上万时每次按键卡顿数百毫秒起。
建议：搜索放后台线程（QThread/QRunnable），新关键词到达取消旧任务，
面板与搜索格子共用一个搜索实例；防抖统一。

### PERF-2 任一目录变化 → 全部格子刷新
`main._on_storage_changed` 收到事件后 400ms 防抖 `refresh_all()`（刷新所有格子）。
QFileSystemWatcher 的信号自带**事件源目录路径**，可建立
"目录 → 对应格子"映射精确刷新（根目录变→根相关、分类子目录变→仅该格子、
映射目录变→仅映射格子）。
影响面：一键整理会同时动多个分类 → 精确刷新法下每次事件只刷新受影响格子，
路径映射的大目录格子不再被无关事件带崩。

### PERF-3 图标缓存满 2000 条时"整体清空"
`get_file_icon` 超阈值 `_FILE_ICON_CACHE.clear()` → 下次刷新全部重新做
白页检测 + Shell 兜底，一次肉眼可见的卡顿尖峰。
建议：清掉最旧的 500 条（FIFO）而非全清。

### 其他小项（代码健康）
- `_run_auto_organize` 中 `_auto_seen` 重复赋值两次（冗余无害）。
- `BUILTIN_GRID_NAMES` 在 widgets.py 与 main.py 各定义一份，应单点维护。
- `handle_size_changed` 拖拽期间每 600ms 落盘一次配置（可改为拖拽结束才落盘）。

## 三、界面优化建议

| 编号 | 建议 | 理由 |
|---|---|---|
| UI-1 | 面板高度按屏幕钳制（`min(760, 屏高-80)`）或加滚动区 | 1366×768 笔记本上 760px 面板被任务栏截断 |
| UI-2 | 全局统一弹窗暗色 QSS（QMessageBox/QInputDialog/QFileDialog） | 从 FileWidget 弹出的确认框是无样式的系统亮色，与全暗界面割裂 |
| UI-3 | 搜索结果显示分类标签（"[文档] 报告.csv"或行尾灰字） | 目前只在 tooltip 里，同名的两处结果无法直接区分 |
| UI-4 | 空格子引导条升级：主文案 + 副文案（"右键可新建/映射/锁定"） | 新用户可发现性 |
| UI-5 | 尺寸调整热区 6px → 8px，并在边缘画细微把手提示 | 小尺寸格子上很难精确命中边缘 |
| UI-6 | 拖入高亮时内容轻微变暗 | 强化"松手即收纳"的反馈 |
| UI-7 | 托盘菜单加"自动整理"开关（与面板同步） | 常用操作免开面板 |
